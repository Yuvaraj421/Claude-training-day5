KEY FILES OVERVIEW
==================

1. main.py - Streamlit Dashboard
   - 5 metric cards (total, high-risk, excursions, avg/max risk, delayed)
   - Risk distribution chart (Plotly bar)
   - Top 5 highest-risk list
   - AI recommendation section
   - Expandable detail views
   - File uploader for custom data
   - Risk threshold slider

2. risk_analyzer.py - Risk Engine
   - PharmaRiskAnalyzer class
   - calculate_risk_scores() → scores each shipment
   - get_high_risk_shipments() → filters by threshold
   - get_temperature_excursions() → detects violations
   - get_risk_distribution() → categorizes risks
   - generate_recommendations() → creates alerts

3. create_sample_data.py - Data Generator
   - Generates 150 pharma shipments
   - Includes random carriers, destinations, products
   - Creates temperature excursions (20 shipments)
   - Adds delays and transit delays
   - Outputs: sample_shipments.xlsx

4. sample_shipments.xlsx - Test Data
   - 150 rows of pharma shipment data
   - Columns: ID, Date, Destination, Product, Qty, Temps, Humidity, Hours, Carrier, Status
   - Pre-generated with realistic scenarios
   - Auto-loads in Streamlit when available


WORKFLOW
========

Step 1: Setup
   $ pip install -r requirements.txt      (2-3 min, pandas compiles)

Step 2: Generate Data (Optional - sample_shipments.xlsx included)
   $ python create_sample_data.py          (creates 150 test shipments)

Step 3: Run Application
   $ streamlit run main.py                (launches at localhost:8501)

Step 4: Use Dashboard
   - Enable "Use sample data" to see 150 shipments
   - OR upload your own Excel file
   - Adjust risk threshold slider (20-80)
   - View metrics, chart, recommendations
   - Expand to see detailed drilldowns
